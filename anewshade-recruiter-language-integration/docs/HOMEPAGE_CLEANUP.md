# Optional homepage cleanup for anewshade.de

These are **not required** for the `/for/*` integration, but they remove credibility friction for recruiters.

## 1. Location

The live portfolio currently presents Berlin / Berlin coordinates, while the application material uses Dresden.

Recommended:

```text
Dresden, Germany · Remote Germany / EU
```

or the more location-neutral:

```text
Germany · Remote
```

Use one location consistently across:

- portfolio
- résumé
- LinkedIn
- application forms

## 2. Future-dated project labels

As of 23 August 2026, any project displayed as September, November or December 2026 appears future-dated.

If those labels are sequence labels rather than release dates, change the presentation.

Better:

```text
PROJECT 07
TSLEARN
```

or:

```text
2026 · Personal project
```

Do not leave a future month on a project unless it genuinely represents a scheduled future release and is clearly labeled as such.

## 3. "10+ Years of Experience"

Keep this only if you can defend what "experience" means in an interview.

A safer formulation if it includes independent/personal development:

```text
10+ years building for the web
```

rather than implying ten years in equivalent salaried software-engineering roles.

## 4. "100% On-Time Delivery"

This is difficult for a recruiter to verify and reads more like agency marketing.

Stronger replacements:

```text
18+ shipped projects
Next.js 16 / React 19
Full-stack · AI · SaaS
TypeScript · PostgreSQL · Node.js
```

Choose a statement that is directly supported by the portfolio.

## 5. Featured-project hierarchy

Do not remove the larger archive. Change what recruiters see first.

Recommended first six:

1. OBCG
2. AdminPilot
3. Kanzlei Intake Suite
4. ERechnungFix
5. Fine Truth
6. LaunchPad

Then show the rest as additional work.

This gives a recruiter a fast path through:

- real operational product
- AI integration
- TypeScript
- PostgreSQL
- legal/professional workflow
- SaaS/payments/auth
